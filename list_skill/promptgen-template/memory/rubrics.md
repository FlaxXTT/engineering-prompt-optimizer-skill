# Rubrics Template

## Default Engineering Prompt Rubric
- Correctness: 30
- Completeness: 20
- Specificity: 20
- Verifiability: 20
- Operational usefulness: 10

## Default Veto Failures
- Fabricated or unverified current technical claims.
- No task signature.
- No metric.
- No clarification trigger for missing critical facts.
- Output cannot be evaluated by examples, tests, citations, schema, or review criteria.
