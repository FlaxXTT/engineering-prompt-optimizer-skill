# Test: Final Output Quality

The final output must include:

- DSPy Signature
- DSPy Modules
- Metric / Rubric
- Iterative Optimization Loop
- 3-5 independent components
- component dependencies
- Todo-list mechanism
- long-running task stability mechanisms
- file and material handling rules
- missing-information handling
- self-check checklist
- prohibitions
- honest boundary saying the skill did not run a real DSPy compiler
- honest boundary that it does not promise absolute non-interruption
- 不声称已经真实运行 DSPy 编译器
- 不承诺绝对永不中断

Reject final outputs that:

- are one-shot prompt rewrites;
- omit Material Capsule targeted reading;
- treat unverified facts as confirmed;
- claim real DSPy compilation happened inside chat;
- promise the model will never interrupt.
