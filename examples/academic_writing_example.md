# Academic Writing Example

## Invocation

```text
[7][论文写作, 文献综述, 降重][我想让模型帮我把论文初稿改成更像人工写的正式毕业论文。]
```

## Required caution

Do not invent citations, school rules, detection results, or claims about the user's project. Ask for Material Capsules:

- thesis draft excerpts;
- school formatting rules;
- project evidence;
- reference list;
- detection report;
- target journal or university standard.

## Targeted reading behavior

For a literature review round, read raw from citation and excerpt capsules. For a formatting round, read the school-format capsule. Do not read all raw material every round.
